# 情報分子生物学 確認テスト

授業スライドと期末試験の過去問（平成30年度・2023年・2024年）をもとにした確認テストです。GitHub Pages で公開しています。

**公開ページ：** https://iwatch-pomi.github.io/information-molecular-biology/

## 使い方

1. 出題範囲（授業回ごと）、形式（選択／記述／両方）、絞り込み（すべて／過去問に出た内容／前回まちがえた問題）、出題数を選びます。
2. 選択問題は選ぶとすぐに正誤と解説が出ます。キーボードの 1〜4 で解答、Enter で次へ進めます。
3. 記述問題は本試験と同じ形式です。答えを書いてから模範解答の骨子とキーワードを確認し、自己採点します。
4. まちがえた問題はブラウザに記録され、次回「前回まちがえた問題」で復習できます。

| ファイル | 内容 |

## 問題の追加

`questions.js` の `QUESTIONS` 配列に追加します。

```js
// 選択問題：c[0] が正解（表示時にシャッフルされる）
{ id: "s99", t: "seq", q: "問題文", c: ["正解", "誤り1", "誤り2", "誤り3"], e: "解説", p: [2024], quiz: true },

// 記述問題
{ id: "w99", t: "seq", type: "w", q: "問題文", a: "模範解答の骨子", k: ["キーワード1", "キーワード2"], p: [2023] },
```

- `t`：分野（`basic` `seq` `struct` `genome` `trans` `prot` `metab` `robot`）
- `p`：期末試験に出た年（省略可）
- `quiz`：毎回の確認問題に出た内容なら `true`（省略可）

内容は個人の学習用です。最終的には授業資料で確認してください。
