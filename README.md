# 情報分子生物学 確認テスト

授業最終回の「まとめ」プリント（スライド13〜18）と期末試験の過去問（平成30年度・2023年・2024年）をもとにした、記述式の確認テストです。期末試験（2026年11月27日）は記述の「説明せよ」形式なので、選択問題ではなく説明問題と用語の意味の問題で構成しています。GitHub Pages で公開しています。

**公開ページ：** https://iwatch-pomi.github.io/information-molecular-biology/

## 使い方

1. 出題範囲（まとめプリントの項目ごと）、問題の種類（説明問題／用語の意味）、絞り込み（すべて／過去問に出た内容／前回書けなかった問題）、順番、出題数を選びます。
2. 答えを書いて（頭の中で言うだけでも可）から「模範解答を見る」を押し、キーワードと模範解答の骨子を確認して自己採点します。キーボードでは Space で模範解答、1〜3 で自己採点、Enter で次へ進めます。
3. 「一部書けた」「書けなかった」問題はブラウザに記録され、次回「前回書けなかった問題」で復習できます。
4. 「模範解答を一覧で読む」で、選んだ範囲の問題と模範解答を通して読めます。

## 問題の追加

`questions.js` の `QUESTIONS` 配列に追加します。

```js
// 説明問題（本試験形式）
{ id: "seq-w9", t: "seq", type: "w", q: "問題文", a: "模範解答の骨子", k: ["キーワード1", "キーワード2"], p: [2023] },

// 用語の意味
{ id: "seq-t9", t: "seq", type: "term", q: "〇〇とは何か。", a: "1〜2文の説明", k: ["キーワード"] },
```

- `t`：分野（`seq` `struct` `genome` `trans` `prot` `metab` `extra`）
- `p`：期末試験に出た年（省略可）
- `quiz`：毎回の確認問題に出た内容なら `true`（省略可）
- `note`：まとめプリントや付箋の書き込み（省略可）

内容は個人の学習用です。最終的には授業資料で確認してください。
